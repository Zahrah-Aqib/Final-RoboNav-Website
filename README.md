# RoboNav | Original React Website

The original React/TypeScript website for the robot navigation project. This is **not** the new scroll-controlled RoboNav-3D website.

## Live websites

- Original React: https://final-robonav-website.vercel.app
- Original Python backend health: https://robonav-python-api.vercel.app/api/health

## What it does

- Classic React homepage with a decorative Three.js robot.
- Editable 2D obstacle grid and step-by-step frontier/path playback.
- From-scratch Python **A*** and **Greedy Best-First Search**.
- Manhattan and Euclidean heuristics; four-direction uniform-cost movement.
- Side-by-side algorithm comparisons, seeded experiment runs, CSV export.
- **Python Visualizations** using real Matplotlib figures generated by FastAPI.
- How It Works, About & Team, and Documentation pages.
- U-shaped obstacle case where A* costs 15 and Greedy costs 39.

No machine learning, account system, database or paid API is required.

## Run locally

Terminal 1 (Python API):

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

Terminal 2 (React, repository root): create `.env.local` with `VITE_API_URL=http://127.0.0.1:8000`, then:

```powershell
npm.cmd ci
npm.cmd run dev
```

The local frontend is `http://localhost:5173` and API documentation is `http://127.0.0.1:8000/docs`.

## Deploy

Two independent Vercel projects use this repository:

- **Original React frontend:** Root `./`, Vite, `npm ci`, `npm run build`, output `dist`, `VITE_API_URL=https://robonav-python-api.vercel.app`.
- **Original Python backend:** Root `backend`, FastAPI. Set `ROBONAV_ALLOWED_ORIGINS=https://final-robonav-website.vercel.app`.

## Verification

```powershell
npm.cmd ci
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

From the `backend` folder, install `requirements-dev.txt` and run `python -m unittest discover -s tests -v`.
